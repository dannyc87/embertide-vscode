# Changelog

All notable changes to this theme are documented here. Format loosely follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0]

Initial release.

- Base and Italic variants, workbench UI + full syntax highlighting
- Language-specific rules for Python (`self`/`cls`), JS/TS (template literals),
  Markdown (headings, bold/italic, code spans, quotes, links, strikethrough),
  decorators, and control-flow keywords
- Semantic token colors, so imports and references resolve by real type
  (class/function/const/etc.), not just TextMate grammar
- Role mapping now defined canonically in
  [embertide's SPEC.md](https://github.com/dannyc87/embertide/blob/main/SPEC.md),
  shared with the [JetBrains edition](https://github.com/dannyc87/embertide-jetbrains)
